- test build: run the build-configuration matrix, on a POSIX system and on
  Windows. The driver builds every cell, does not stop at the first failure,
  and exits non-zero if any cell failed; each build's log is under logs/ in
  the master directory.
    sh maintainer/gen-build-matrix.sh -d ../build-matrix -x --enable-unit-tests
    sh ../build-matrix/build-all.sh
  and on Windows:
    pwsh maintainer\gen-build-matrix.ps1 -Dir ..\build-matrix
    pwsh ..\build-matrix\build-all.ps1
  "-x --enable-unit-tests" appends that option to every cell, so each
  configuration is tested and not only built. It needs CMocka, and nothing
  probes for it: where CMocka is absent, configure fails in every cell rather
  than skipping them. A cell whose optional library is
  missing is skipped rather than failed, and matrix-info.txt says which - read
  that before taking a short matrix for a clean one.
  See doc/maintainer-build-matrix.md for the cells and the prerequisites.

- validate the tarball with check-dist, on a POSIX system and on Windows. It
  reads nothing from the tree the tarball was rolled from - the build harness,
  the source, the man pages and the ABI contract all come out of the tarball,
  because a file missing from it is exactly the defect this is looking for.
    sh maintainer/check-dist.sh lame-<version>.tar.gz /tmp/distcheck
  and on Windows:
    pwsh maintainer\check-dist.ps1 lame-<version>.tar.gz C:\temp\distcheck
  "make distcheck" is one of its checks - a VPATH build, install, installcheck,
  uninstall and re-dist - so that does not have to be run separately. Every
  check reports PASS, FAIL, SKIP or N/A and the run continues to the end; only
  a FAIL makes the exit status non-zero. SKIP means a prerequisite is missing
  on this machine, N/A that the check cannot apply to this platform at all.
  Run both halves: the native Windows build is not reachable from a POSIX
  shell, and configure, "make distcheck" and the unit tests do not exist in the
  native Windows build.
  See doc/maintainer-check-dist.md for the full check list and the opt-in
  flags (--maintainer-mode, --audio-dir, --coverage, --sanitizers).
